# EcoSort AI — Demo Prototype

## Run
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Demo
1. Upload any waste image.
2. Select a sample object.
3. Click "Analyze with EcoSort AI".
4. Show the AI result, disposal action and sustainability tip.

This version is intentionally a presentation/demo prototype. The sample classification is simulated; it does not claim to perform real image classification.
